# 诗词音频

固件内置 16 kHz 单声道 16 位 PCM，全部由 `tools/build_poetry_audio.py`
生成。本应用不包含第三方音效包。

## 古诗朗读

`assets/audio/narration/` 下的三段朗读使用 Windows 中文系统语音
（Microsoft Huihui），通过 System.Speech 以适合七岁孩子的慢速朗读，
再重采样为 16 kHz 单声道并裁剪。录音文件已提交到仓库，保证离线构建可复现。
语音模型本身不随固件分发。

| 诗篇编号 | 篇名 | 朗读内容 |
| --- | --- | --- |
| 7 | 春晓 | 篇名、作者、四句全文 |
| 2 | 静夜思 | 篇名、作者、四句全文 |
| 16 | 登鹳雀楼 | 篇名、作者、四句全文 |

## 背景音乐

12.8 秒循环由 C 大调五声音阶拨弦、缓慢低音铺底和稀疏高音泛音合成，
完全在 `tools/build_poetry_audio.py` 中生成，不使用外部录音。

## 交互音效

五种柔和提示音（移动、确认、答对、答错、解锁）由同一脚本用正弦包络合成，
刻意避开数学配对游戏里的光弹与怪兽吼叫风格。
